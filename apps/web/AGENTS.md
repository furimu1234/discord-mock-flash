# AGENTS.md - Web UI (`apps/web`)

本ドキュメントは、ブラウザ操作画面（テスト画面 & 管理画面）の開発ガイドラインおよび仕様を定義します。

---

## 1. 概要
- **役割**: Discord風クライアントシミュレータ（テスト画面）およびサーバー・ユーザー管理画面（管理画面）の提供
- **アクセス先**: CLI起動時に発行されるローカルURL（例: `http://localhost:3000`）

---

## 2. ツールチェイン & パッケージ管理
- **パッケージマネージャー**: `pnpm` (Workspace配下)
- **主要スタック**: React / Vite / Tailwind CSS
- **状態管理**: WebSocket / SSE によるサーバー（apps/server）とのリアルタイム双方向同期

---

## 3. 画面仕様
1. **テスト画面 (Discord Client Emulator)**:
   - **ユーザー切り替え**: シミュレート対象のダミーユーザーを選択して即時ログイン。
   - **インタラクション**: ログインユーザーとしてメッセージ送信、スラッシュコマンド実行、ボタン押下。
   - **DM隔離**: 自ユーザー宛てのDMのみ表示。別ユーザーのDMは閲覧不可。
   - **ボイスチャンネル (VC)**: Botが参加中のVCにログインユーザーが接続すると、Web Audio経由で音声を再生。切断すると即時停止。
   - **右側サイドバー (タブ切り替え)**:
     - **メンバーリスト**: BOT・オンラインユーザー一覧表示。ワンクリックでのなりすましログイン切り替えやVC参加状態を表示。
     - **テストケース**: スラッシュコマンド疎通、メッセージ送信、コンポーネントボタン押下、VC接続、DM隔離などのテストシナリオ実行および合否・実行ログの確認。
2. **管理画面 (Admin Dashboard)**:
   - ダミーユーザー、ギルド、チャンネル、ロールのCRUD作成・編集・削除。
   - モック状態のリセット、JSONシードデータのインポート/エクスポート。
