# End-to-End & Cross-Client Compatibility Tests (`tests/`)

このディレクトリには、Mockサーバー本体と各クライアント（JavaScript / Python）、およびBotライブラリ（`discord.js`, `discord.py` 等）を組み合わせた結合テストおよびクロス言語互換性検証テストを配置します。

---

## 主な検証シナリオ
1. **Zero Code Changes 検証**:
   - `discord.js` / `discord.py` のサンプルBotコードを変更せず、Mockのエンドポイント指定のみでログイン・Gateway接続できること。
2. **インタラクションシナリオ**:
   - スラッシュコマンド受信、ボタン押下、モーダル送信がダミーユーザーからBotへ正しく伝搬すること。
3. **DM隔離シナリオ**:
   - BotからのDMが特定ユーザーのみに届き、他ユーザーから閲覧できないこと。
4. **ボイスチャンネル (VC) 音声再生シナリオ**:
   - BotがVCに接続して音楽ストリームを送信している状態で、ダミーユーザーが接続した際に音声が届くこと。
